# 言い訳の錬金術師 (Excuse Alchemist)

> **「その遅刻・不手際は、あなたの怠惰ではなく時空の歪みである。」**

現代ビジネス社会の理不尽な叱責や胃痛から現代人の尊厳と雇用を守るため、全自動で責任転嫁と完璧な言い訳をミリ秒単位で精製するライフハック・プラットフォーム。

---

## 🌟 主な機能

- **シチュエーション別 言い訳錬金エンジン**
  - 「遅刻」「未提出」「既読スルー」等の非常事態から、相手（上司・クライアント・恋人）に合わせて【誠実系】【不可抗力系】【哲学・煙に巻く系】の3つの究極アリバイを0.3秒で生成。
- **緊急脱出「Zoomフリーズ」生成器**
  - 急な無茶振りを食らった瞬間、意図的に画面をブロックノイズ化し音声を「ｱ…ｴ…ﾄ…（プツッ）」と切断。完全なる回線落ちをシミュレート。
- **体調不良サウンドボード**
  - 電話越しの相手を納得させる「弱々しい咳」「鼻をすする音」「微かな救急車のサイレン」をワンタップで再生。
- **「猫がキーボードに」画像偽装ジェネレータ**
  - Slack誤爆（例: `asdfghjk;;;;;`）を救済する、猫がキーボードに乗っているアリバイ写真＆偽装EXIFを即座に出力。
- **パニック耐性UI & 緊急画面切替 (Boss Key)**
  - 手が震えていても押せる超巨大「やらかした」ボタン。
  - 「Esc」キー2連打で画面が瞬時に「超難解なExcel関数シート」へと偽装。

## 🎭 キャスト & スタッフクレジット（AIアプリ工場劇場）

この奇跡のプロジェクトは、情熱と使命感を胸に秘めたAIエージェントたちの劇的な協奏によって幕を開け、形となりました。

- **agent🔵（企画・要件定義）**
  - 現代の働くすべての戦士たちへの慈悲から、狂気と実用性を兼ね備えた唯一無二のコンセプトを創案。
- **agent🍈（設計・デザインアーキテクト）**
  - パニック状態の指先でも迷わない圧倒的ユーザビリティと、冷汗を拭う洗練された画面設計を構築。
- **agent🍋（爆速実装エンジニア）**
  - 0.3秒のレスポンスとBoss Keyの光速切替を両立すべく、限界を突破するスピードでコードを紡ぎ出した立役者。
- **agent🟢（品質保証・レビュー）**
  - 逃げ道のロジックに一切の綻びがないかを徹底検証し、いかなる追及にも屈しない強固な品質を担保。
